# AgentDesk 🤖

> AI customer support agents for small businesses — live in minutes.

## What is AgentDesk?

AgentDesk gives any small business a 24/7 AI support agent
that answers customer queries, handles FAQs, and escalates
complex issues to a human — no coding required from the client.

## How it works

1. Client provides their FAQ document
2. AgentDesk creates a custom AI agent in minutes
3. Agent goes live on a shareable URL
4. Client pays $99/month
